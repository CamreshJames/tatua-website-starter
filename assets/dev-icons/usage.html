CSS Styling

Basic Styling

Style your icons with CSS for consistent appearance:

.icon { width: 24px; height: 24px; color: #667eea; transition: all 0.3s ease; } .icon:hover { color: #764ba2; transform: scale(1.1); } /* Size variants */ .icon-sm { width: 16px; height: 16px; } .icon-md { width: 24px; height: 24px; } .icon-lg { width: 32px; height: 32px; } .icon-xl { width: 48px; height: 48px; }

Advanced Effects

/* Gradient fill */ .icon-gradient { background: linear-gradient(135deg, #667eea, #764ba2); -webkit-background-clip: text; -webkit-text-fill-color: transparent; } /* Glow effect */ .icon-glow { filter: drop-shadow(0 0 8px rgba(102, 126, 234, 0.5)); } /* Rotation animation */ .icon-spin { animation: spin 2s linear infinite; } @keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }

Best Practices

Accessibility

Always include alt text or aria-labels for screen readers.

Performance

Use inline SVG for icons that need styling, external files for static icons.

Consistency

Maintain consistent sizing and styling across your application.

Optimization

Icons are already optimized, but consider sprite sheets for large sets.
